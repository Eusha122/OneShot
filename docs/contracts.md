# Shared Contracts

These contracts define the stable shape used across frontend, backend, and future workers.

## Learning Modes

- `explain_simply`
- `exam_mode`
- `visual_mode`
- `step_by_step`
- `fast_revision`
- `challenge_me`

## Pipeline Status Events

- `searching_textbook`
- `retrieving_notes`
- `checking_internet_sources`
- `generating_answer`
- `generating_graph`
- `loading_simulation`

## Source Trust

- High: SSC textbooks, board questions.
- Medium: uploaded notes and teacher material unless promoted by metadata.
- Variable: internet search results.

## Visual Blocks

Visual blocks are deterministic payloads. The AI proposes structured data; the frontend renderer controls formulas, animation, replay, and layout.

Current visual block types:

- `physics.projectile`: speed, angleDegrees, gravity.
- `math.sineGraph`: amplitude, frequency, phase.
